# Книги Аудио — Android-приложение для knigi-audio.com

## Как это устроено

**Плеер.** На сайте PlayerJS запускается так:

```js
new Playerjs({id:"playerjs1", file:"https://…/87271.pl.txt"})
```

Файл `.pl.txt` — это JSON-плейлист PlayerJS с прямыми ссылками на mp3:

```json
[{"title":"Глава 1","file":"https://…/files/01.mp3"}, …]
```

Приложение **не встраивает веб-плеер в WebView**. Оно:
1. открывает страницу книги,
2. достаёт параметр `file` из `new Playerjs({...})`,
3. скачивает плейлист,
4. отдаёт mp3 нативному плееру Android (Media3 / ExoPlayer).

Плюсы такого подхода:
- звук не прерывается при выключенном экране и в фоне;
- есть уведомление с кнопками, управление с экрана блокировки, наушников и часов;
- пауза, когда выдернули наушники или пришёл звонок;
- работают перемотка ±15/30 сек, скорость 0.75–2×, таймер сна;
- прогресс каждой книги запоминается («Продолжить с главы 5, 12:34»).

Поддерживаются все форматы плейлиста PlayerJS: JSON, JSON с папками (`folder`), строка `[Название]url,[Название]url`, прямая ссылка на mp3.

**Данные с сайта** (парсер `data/Site.kt`):
| Что | Откуда |
|---|---|
| Новинки | `/`, `/page/N/` |
| Жанры | `/<жанр>/`, `/<жанр>/page/N/` |
| Поиск | POST `/index.php?do=search` (стандартный поиск DLE) |
| Книга | `h1`, `.fposter img`, `ul.flist li`, `.fdesc` |

Старые книги, у которых на сайте вместо PlayerJS стоит платный фрагмент («Купить за …»), приложение помечает и предлагает открыть их на сайте.

## Экраны
- **Главная** — новинки и лента по жанрам (чипсы сверху), бесконечная прокрутка.
- **Поиск** — ищет по мере набора текста.
- **Книга** — обложка, автор, чтец, описание, список глав, кнопки «Слушать»/«Продолжить» и «В избранное».
- **Плеер** — большая обложка, перемотка, ±15/30 сек, главы, скорость, таймер сна.
- **Моя полка** — «Продолжить слушать» и «Избранное» (хранятся на телефоне).
- Мини-плеер внизу на всех экранах.

## Как собрать APK

### Вариант 1. Android Studio (на своём компьютере)
1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. **File → Open** → выберите папку `KnigiAudio`.
3. Дождитесь окончания синхронизации Gradle (первый раз 5–10 минут: скачиваются библиотеки).
   Если Studio предложит обновить Android Gradle Plugin — можно соглашаться.
4. Подключите телефон по USB (на телефоне: Настройки → О телефоне → 7 раз нажать «Номер сборки» → в «Для разработчиков» включить «Отладка по USB») и нажмите зелёную кнопку **Run ▶**.
5. Готовый APK-файл: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**,
   файл появится в `app/build/outputs/apk/`. Его можно скинуть на любой телефон и установить.

### Вариант 2. Без установки Android Studio — через GitHub
1. Создайте репозиторий на GitHub и загрузите туда содержимое папки `KnigiAudio`.
2. Сборка запустится автоматически (вкладка **Actions** → «Build APK»).
3. Через ~5 минут скачайте APK в разделе **Artifacts** этой сборки.

## Что настроить под себя
- Название: `app/src/main/res/values/strings.xml`.
- Цвета: `ui/Theme.kt` (объект `Palette`).
- Список жанров: `data/Site.kt` → `genres`.
- Иконка: `res/drawable/ic_launcher_foreground.xml`
  (или правый клик по `res` → New → Image Asset).
- Для Google Play: поменяйте `applicationId` в `app/build.gradle.kts` и подпишите сборку своим ключом
  (Build → Generate Signed App Bundle).

## Если сайт поменяет шаблон
Вся привязка к вёрстке собрана в одном файле — `data/Site.kt` (CSS-селекторы и регулярка для PlayerJS).
Надёжнее всего добавить на сайт небольшой JSON-API для приложения: тогда смена дизайна сайта не сломает приложение.
